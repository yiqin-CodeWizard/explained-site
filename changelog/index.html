KNOW WHAT YOU ARE INSTALLING

Versions and manual updates.

The current default download is extension-wasm-offline v0.2.0, the API edition. Website improvements do not automatically update an installed extension.

On this page

  1. v0.2.0 — API edition
  2. Update an unpacked API extension
  3. Earlier website editions

v0.2.0 — API edition

  • Explanations use DeepSeek’s official model API with your own key. News, time-sensitive queries and Explain a little more also use DeepSeek Search.
  • Lookups start from the selection icon or Ctrl+X (⌘X on Mac). Highlighting and copying alone send nothing.
  • Setup verifies a supplied key. The key is stored locally and reading-page scripts receive sanitized settings.
  • Keep it short restores the cached answer; pausing, closing or changing relevant settings cancels active work.
  • Download v0.2.0 and verify its checksum
  • Set up your API key

Update an unpacked API extension

  • Download the current ZIP and check its displayed version. Extract it; manifest.json is at the ZIP root.
  • Replace the files in the folder used by the installed unpacked API edition. Check that manifest.json is directly in that folder rather than inside an extra nested directory.
  • Open chrome://extensions, reload the unpacked extension and refresh existing reading pages. Open API settings if setup is requested.
  • Downloading or unzipping alone does not update the files Chrome is currently using.
  • Get help if the updated extension does not appear

Earlier website editions

The earlier Explained v0.1.5 website edition used a DeepSeek website connection. Its setup and query behavior differ from the API edition, which requires an API key. Refer to the version-specific privacy policy if you are using an earlier edition.

Published versioned download URLs and checksums remain stable. A website navigation or tutorial update does not change the bytes of an existing extension ZIP.

  • Read the version-specific privacy policy (English)
