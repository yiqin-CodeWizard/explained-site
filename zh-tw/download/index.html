API 版 · v0.2.0

下載 extension-wasm-offline v0.2.0，即 Explained 的 Chrome API 版。需要自備 DeepSeek API 金鑰及網路連線；模型與搜尋呼叫由你的 DeepSeek 帳戶計費。

Chrome 114+ · 需要網路 · 自備 DeepSeek API 金鑰

  1. 01下載 v0.2.0 API 版並解壓縮。
  2. 02開啟 chrome://extensions 並啟用開發人員模式。
  3. 03選擇載入未封裝項目，並找到包含 manifest.json 的資料夾。
  4. 04在設定中填入 DeepSeek API 金鑰，點擊 Enable lookups，再點擊 Start exploring。已開啟的閱讀頁面請重新整理一次。

API 金鑰設定 (English)

API 金鑰儲存在本機擴充功能儲存空間。觸發查詢時，所選文字、可選上下文及搜尋詞會傳送至 DeepSeek 官方 API；呼叫由你的 DeepSeek 帳戶計費。 閱讀完整隱私說明 (English).

進入文章體驗區

你的閱讀，由你決定。
