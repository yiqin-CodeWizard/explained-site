你可能想知道

需要 API 金鑰嗎？

本預覽版不需要付費 API 金鑰，使用瀏覽器中的 DeepSeek 網站。你可能需要登入，且仍受 DeepSeek 本身使用限制約束。

哪些內容會被分享？

啟用查詢後，擴充功能使用你的 DeepSeek 網站登入狀態，將選取的詞句和可選的最多 600 個附近字元傳送至 DeepSeek。你可以查看、關閉上下文或暫停查詢。DeepSeek 可能依其政策和你的帳戶設定保留及使用對話。

哪些頁面可以使用？

支援 Chrome 114 及以上版本中的一般 HTML 閱讀頁面。本預覽版不支援 PDF、瀏覽器設定頁面和文件編輯器。
