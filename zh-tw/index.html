讀完一百萬 token，需要什麼？

語言模型處理長文件時，需要在生成回答的過程中持續利用前文資訊。一百萬 token 上下文會讓這一挑戰顯著增加。DeepSeek-V4 技術報告介紹了兩個模型，目標是讓如此大規模的輸入更容易實際使用。

你可能想知道

需要 API 金鑰嗎？

需要。下載的 API 版需要自備 DeepSeek API 金鑰及網路連線，模型與搜尋呼叫由你的 DeepSeek API 帳戶計費。DeepSeek 網站登入不能替代 API 金鑰。

哪些內容會被分享？

點擊選取圖示或使用快速鍵時，所選文字及可選的最多 600 個附近字元會傳送至 DeepSeek。News、時效性查詢和「多解釋一點」也會進行網路搜尋。僅選取或複製不會傳送請求。

哪些頁面可以使用？

支援 Chrome 114 及以上版本中的一般 HTML 閱讀頁面。本預覽版不支援 PDF、瀏覽器設定頁面和文件編輯器。
