需要時，幫你一下

找回順暢閱讀的節奏。

從你遇到的現象開始排查。以下步驟適用於 extension-wasm-offline v0.2.0 API 版。

本頁內容

  1. 沒有出現圖示或解釋
  2. 卡片提示 API 錯誤
  3. News 或更詳細的解釋沒有來源

  5. 控制上下文與暫停查詢

沒有出現圖示或解釋

  • 使用 Chrome 114 或更新版本，開啟普通 HTML 文章。安裝或重新載入擴充功能後，請重新整理已開啟的頁面。
  • 開啟擴充功能工具列，確認查詢已啟用、目前網站沒有暫停。尚未設定金鑰時，先完成 API 設定。
  • 在閱讀正文中選取一小段詞句，然後點擊小圖示，或按 Ctrl+X（Mac 為 ⌘X）。僅選取或複製不會傳送請求。
  • 輸入框和編輯器中的快速鍵保留正常剪下行為；解釋快速鍵僅用於支援的閱讀選區。
  • 設定 DeepSeek API 金鑰（英文）
  • 開啟一篇體驗文章

卡片提示 API 錯誤

  • 缺少金鑰或金鑰無效：從擴充功能工具列開啟 API settings，填入或更換金鑰。登入 DeepSeek 網站不能代替 API 設定。
  • 餘額不足或沒有存取權限：前往 DeepSeek 官方平台檢查 API 帳戶餘額與權限。
  • 請求過於頻繁、服務無法使用或逾時：稍等片刻，檢查網路後再點擊 Retry。重複點擊可能增加請求。

News 或更詳細的解釋沒有來源

News、時效性選區以及 Explain a little more 會先呼叫 DeepSeek Search。搜尋失敗或缺少可用證據時，擴充功能會顯示問題，不會編造即時報導。

請核對日期並開啟原始來源。生成的解釋與摘要可能有誤。Keep it short 會恢復已快取的簡短回答。

哪些頁面可以使用

目前支援普通 HTML 閱讀頁面。瀏覽器設定頁、PDF 閱讀器和文件編輯器不在本預覽版的支援範圍內。瀏覽器的網站存取權限設定也可能阻止擴充功能執行。

以 HTML 形式發布的研究文章可以用於這一閱讀流程。同一篇論文在 PDF 閱讀器中開啟時，仍屬於不支援的頁面。

控制上下文與暫停查詢

工具列可以全域暫停、暫停某個網站、選擇解釋語言，以及開啟或關閉附近上下文。開啟上下文時，會隨選區傳送最多 600 個附近字元。

金鑰和偏好儲存在本機擴充功能儲存空間。閱讀頁腳本只能取得過濾後的設定，不能讀取金鑰。本機儲存空間並不是加密保險箱。

  • 閱讀完整隱私政策（英文）

仍然無法解決？

回報時提供擴充功能版本、Chrome 版本、頁面類型、可見錯誤和重現步驟。截圖及 issue 中請去掉 API 金鑰、私人閱讀內容和帳戶資訊。

  • 在 GitHub 回報問題

設定完成，開始一篇好閱讀。

開啟體驗文章，選取詞句後點擊圖示，或按 Ctrl+X（Mac 為 ⌘X），開始第一次查詢。
