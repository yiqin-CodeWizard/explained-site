# Reporting a vulnerability

Version 0.1.x is an experimental preview. There is no guaranteed response time or security-support SLA.

For a suspected credential leak, cross-origin data exposure, source-link injection or another vulnerability, use GitHub’s **Security → Report a vulnerability** private-reporting feature if enabled. If unavailable, first open a minimal issue asking the maintainer for a private contact route; do not include vulnerability details, exploits, private URLs or sensitive material there. Wait for a private route before sharing details.

Include the version, a minimal reproduction with synthetic data, impact and suggested remediation if available. Never include live cookies, tokens, authorization headers, proofs or private chats. Do not test against other users’ accounts or bypass website verification or limits.

This project is independent of DeepSeek. Service-side issues should be reported through the service’s own official channels.
