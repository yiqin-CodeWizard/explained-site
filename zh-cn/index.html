读完一百万 token，需要什么？

语言模型处理长文档时，需要在生成回答的过程中持续利用前文信息。一百万 token 上下文会让这一挑战显著增加。DeepSeek-V4 技术报告介绍了两个模型，目标是让如此大规模的输入更容易实际使用。

你可能想知道

需要 API 密钥吗？

需要。下载的 API 版需要自备 DeepSeek API 密钥及网络连接，模型和搜索调用由你的 DeepSeek API 账户计费。DeepSeek 网站登录不能替代 API 密钥。

哪些内容会被分享？

点击划选图标或使用快捷键时，所选文字及可选的最多 600 个附近字符会发送至 DeepSeek。News、时效性查询和“多解释一点”也会进行网络搜索。仅划选或复制不会发送请求。

哪些页面可以使用？

支持 Chrome 114 及以上版本中的普通 HTML 阅读页面。本预览版不支持 PDF、浏览器设置页面和文档编辑器。
