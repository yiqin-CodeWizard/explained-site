AI 与医学阅读约 1 分钟简体中文

为癌症疗法腾出新的可能

CAR T 细胞疗法通过改造免疫细胞来攻击癌症，已经帮助治疗了一些血液肿瘤。Generate 希望重新设计这一疗法的一部分，让它也能应对实体瘤。不同类型的癌症，给治疗带来的挑战也不同。

团队把注意力放在这些细胞携带的遗传指令上。如果能缩短其中一个片段，就可能腾出空间，加入适用于其他癌症的指令。六位科学家使用 Claude Code，为这个片段探索不同的设计。

据 Anthropic 报道，其中一个候选设计比常规版本短约 70%。实验室测试发现，采用这一设计的细胞产生了约十倍数量的受体，攻击肿瘤细胞的效率更高，保持活性的时间也更长。

这些发现来自早期设计的实验室测试，还不能说明最终疗法在患者身上的表现。这个案例展示了一种合作方式：AI 提出可以验证的方案，科学家将其做出来、测量效果，再决定下一步研究什么。

数学与科学发现阅读约 1 分钟简体中文

从 AI 证明，到共同理解

数学中的波在集中时，最极端的状态可能只会短暂出现。局部光滑性猜想讨论的，是在时间上取平均之后，这种集中会受到怎样的限制。OpenAI 报道，其模型给出了适用于所有维度的证明，并对其他长期悬而未决的问题产生影响。

这份公告还介绍了计算机科学和物理学方面的结果。在这些领域，最初的输出之后还有一项工作：让其他研究者读懂论证、检查推理，并弄清它究竟改变了什么。

对于数学结果，OpenAI 公开了文字论证，以及使用证明检查系统 Lean 形式化的版本。对于其他结果，外部研究者正在组织合作，并分别决定底层材料的发布方式。

这一流程强调独立审查。参与者可以讨论工作，也可以发表自己的结论。通过检查的证明与清楚易懂的解释各有作用：前者验证形式化步骤，后者帮助学术共同体理解背后的思想、假设与影响。

AI 与长上下文阅读约 1 分钟简体中文

读完一百万 token，需要什么？

语言模型处理长文档时，需要在生成回答的过程中持续利用前文信息。一百万 token 上下文会让这一挑战显著增加。DeepSeek-V4 技术报告介绍了两个模型，目标是让如此大规模的输入更容易实际使用。

核心变化是一套混合注意力系统。其中一部分先压缩已存储的信息，再挑选相关条目；另一部分采用更强的压缩，同时对压缩后的条目保留密集注意力。两者结合，减少处理长序列所需的资源。

报告在一百万 token 的条件下，将 DeepSeek-V4-Pro 与 DeepSeek-V3.2 作比较。生成单个 token 时，前者的推理浮点运算量为后者的 27%，KV 缓存为后者的 10%。这些数字描述的是指定比较条件下的计算量和注意力缓存。

阅读效率指标时，区分它们的含义很有必要。更低的计算量和内存需求，可以让持续时间更长的任务更可行，但不能单凭这些数字判断响应速度、价格或回答质量。论文将这些节省与更长的推理、跨多份文档的任务等后续研究联系起来。

你可能想知道

需要 API 密钥吗？

需要。下载的 API 版需要自备 DeepSeek API 密钥及网络连接，模型和搜索调用由你的 DeepSeek API 账户计费。DeepSeek 网站登录不能替代 API 密钥。

哪些内容会被分享？

点击划选图标或使用快捷键时，所选文字及可选的最多 600 个附近字符会发送至 DeepSeek。News、时效性查询和“多解释一点”也会进行网络搜索。仅划选或复制不会发送请求。

哪些页面可以使用？

支持 Chrome 114 及以上版本中的普通 HTML 阅读页面。本预览版不支持 PDF、浏览器设置页面和文档编辑器。

API 版 · v0.2.0

下载 extension-wasm-offline v0.2.0，即 Explained 的 Chrome API 版。需要自备 DeepSeek API 密钥及网络连接；模型与搜索调用由你的 DeepSeek 账户计费。

  1. 01下载 v0.2.0 API 版并解压。
  2. 02打开 chrome://extensions 并启用开发者模式。
  3. 03选择加载已解压的扩展程序，并找到包含 manifest.json 的文件夹。
  4. 04在设置中填入 DeepSeek API 密钥，点击 Enable lookups，再点击 Start exploring。已打开的阅读页面请刷新一次。

API 密钥保存在本机扩展存储中。触发查询时，所选文字、可选上下文及搜索词会发送至 DeepSeek 官方 API；调用由你的 DeepSeek 账户计费。 阅读完整隐私说明.
