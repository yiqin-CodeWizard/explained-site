你可能想知道

需要 API 密钥吗？

本预览版不需要付费 API 密钥，使用浏览器中的 DeepSeek 网站。你可能需要登录，且仍受 DeepSeek 自身使用限制约束。

哪些内容会被分享？

启用查询后，扩展使用你的 DeepSeek 网站登录状态，将选中的词句和可选的最多 600 个附近字符发送至 DeepSeek。你可以查看、关闭上下文或暂停查询。DeepSeek 可能根据其政策和你的账户设置保留及使用对话。

哪些页面可以使用？

支持 Chrome 114 及以上版本中的普通 HTML 阅读页面。本预览版不支持 PDF、浏览器设置页面和文档编辑器。

Explained 是一款实验性的 Chrome 扩展。下载并加载到 Chrome，让下一次遇到的陌生词句多一分清晰。

  1. 01下载扩展并解压。
  2. 02打开 chrome://extensions 并启用开发者模式。
  3. 03选择加载已解压的扩展程序，并找到包含 manifest.json 的文件夹。
  4. 04完成扩展设置，点击“Start exploring”，开始体验文章。
