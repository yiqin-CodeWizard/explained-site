v0.2.0 — API 版

  • 使用自己的密钥调用 DeepSeek 官方模型 API。News、时效性查询和 Explain a little more 也会使用 DeepSeek Search。
  • 通过划选图标或 Ctrl+X（Mac 为 ⌘X）触发查询；仅划选或复制不会发送请求。
  • 设置时验证密钥。密钥保存在本机，阅读页脚本只获得过滤后的设置。
  • Keep it short 恢复缓存回答；暂停、关闭或更改相关设置会取消正在进行的请求。
  • 下载 v0.2.0 并核对校验和
  • 设置 API 密钥

手动更新解压加载的 API 扩展

  • 下载当前 ZIP，核对显示的版本，然后解压。manifest.json 位于 ZIP 根目录。
  • 替换已安装 API 版所使用文件夹中的文件。确认 manifest.json 直接位于该文件夹中，没有多嵌套一层目录。
  • 打开 chrome://extensions，重新加载解压的扩展，再刷新已打开的阅读页面。如果提示设置，请打开 API settings。
  • 仅下载或解压文件，不会更新 Chrome 正在使用的扩展文件。
  • 更新后没有反应时查看帮助

较早的网站连接版本

较早的 Explained v0.1.5 网站版使用 DeepSeek 网站连接，其设置方式和查询行为与需要 API 密钥的新版本不同。仍在使用旧版时，请查看按版本区分的隐私政策。

已发布的版本化下载地址与校验和保持稳定。网站导航或教程更新，不会改变现有扩展 ZIP 的字节。
