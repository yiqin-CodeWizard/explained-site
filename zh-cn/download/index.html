API 版 · v0.2.1

从 Chrome 应用商店安装 Explained。需要自备 DeepSeek API 密钥及网络连接；模型与搜索调用由你的 DeepSeek 账户计费。

Chrome 114+ · 需要网络 · 自备 DeepSeek API 密钥

  1. 01打开 Chrome 应用商店中的 Explained 页面，点击添加至 Chrome。
  2. 02查看所需权限，然后点击添加扩展程序确认。
  3. 03在设置中填入 DeepSeek API 密钥，点击 Enable lookups。
  4. 04点击 Start exploring。已打开的阅读页面请刷新一次。

API 密钥设置

API 密钥仅保存在当前浏览器会话的内存中，重启 Chrome 或重新加载／更新扩展后需重新输入。触发查询时，所选文字、可选上下文及搜索词会发送至 DeepSeek 官方 API；调用由你的 DeepSeek 账户计费。 阅读完整隐私说明 (English).

打开体验文章，划选词句后点击图标，或按 Ctrl+X（Mac 为 ⌘X），开始第一次查询。

你的阅读，由你决定。

此版本通过你自己的密钥调用 DeepSeek 官方 API，密钥仅保存在当前浏览器会话的内存中，偏好保存在本机；重启 Chrome 或重新加载／更新扩展后需重新输入密钥。触发查询时，所选文字、可选上下文及搜索词会发送至 DeepSeek。开发者不保存查询历史；DeepSeek 按其 API 政策处理提交的数据。 阅读完整隐私说明.
