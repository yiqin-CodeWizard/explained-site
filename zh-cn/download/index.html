API 版 · v0.2.0

下载 extension-wasm-offline v0.2.0，即 Explained 的 Chrome API 版。需要自备 DeepSeek API 密钥及网络连接；模型与搜索调用由你的 DeepSeek 账户计费。

Chrome 114+ · 需要网络 · 自备 DeepSeek API 密钥

  1. 01下载 v0.2.0 API 版并解压。
  2. 02打开 chrome://extensions 并启用开发者模式。
  3. 03选择加载已解压的扩展程序，并找到包含 manifest.json 的文件夹。
  4. 04在设置中填入 DeepSeek API 密钥，点击 Enable lookups，再点击 Start exploring。已打开的阅读页面请刷新一次。

API 密钥设置

API 密钥保存在本机扩展存储中。触发查询时，所选文字、可选上下文及搜索词会发送至 DeepSeek 官方 API；调用由你的 DeepSeek 账户计费。 阅读完整隐私说明 (English).
