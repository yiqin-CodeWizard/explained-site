首页/API 密钥设置

一个密钥，连接你自己的账户

设置你的 DeepSeek API 密钥。

将 Explained 连接到你自己的 DeepSeek API 账户，再由你决定何时发送阅读查询。本教程适用于 v0.2.0。

本页内容

  1. 1. 打开官方密钥页面
  2. 2. 在扩展设置中填写密钥
  3. 3. 开始第一次查询
  4. 4. 更换或保留已有密钥
  5. 了解计费与存储

1. 打开官方密钥页面

登录 DeepSeek 开放平台，通过 API 密钥管理页面创建或获取密钥。账户和计费设置请以平台当前说明为准。

DeepSeek 网站登录状态与 API 密钥不同。API 版不使用 chat.deepseek.com 连接标签页。

  • 打开 DeepSeek API 密钥管理

2. 在扩展设置中填写密钥

  • 安装 Chrome 扩展；如果已经安装，从扩展工具栏打开 API settings。
  • 将密钥粘贴到 DeepSeek API key 输入框，并决定是否分享附近上下文。
  • 点击 Enable lookups。设置会通过模型列表 API 验证密钥，不会提交阅读文字，也不会启动模型或搜索查询。
  • 下载并安装 Explained

3. 开始第一次查询

点击 Start exploring，或直接打开文章体验区。安装前已经打开的阅读页面，请刷新一次。

划选词句，再点击旁边的图标，或按 Ctrl+X（Mac 为 ⌘X）。只有主动触发选区，才会发起模型请求。News、时效性查询和 Explain a little more 也会使用搜索。

  • 进入文章体验区

4. 更换或保留已有密钥

再次打开 API settings 可以更换密钥。如果设置提示已保存密钥，输入框留空会保留原密钥并重新验证。

不要把密钥粘贴到阅读文章、GitHub issue 或公开截图中。如果怀疑泄露，请通过官方平台管理或撤销密钥，再更新扩展设置。

了解计费与存储

模型和搜索调用由你的 DeepSeek API 账户计费。实时价格、账户权限与余额请在官方平台查询；本页不承诺免费额度或固定的单次查询价格。

密钥保存在此设备的本机扩展存储中，并附在后台 API 请求上。阅读页面的内容脚本不会获得密钥。提交敏感文字前，请阅读完整政策。

  • 排查密钥与连接问题
  • 阅读隐私政策（英文）

设置完成，开始一篇好阅读。

打开体验文章，划选词句后点击图标，或按 Ctrl+X（Mac 为 ⌘X），开始第一次查询。
