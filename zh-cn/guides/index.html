一步一步，读得更明白

从设置开始，到读懂一篇文章。

从 API 密钥设置到研究文章阅读，按照实际步骤学习使用 Explained。

01

设置你的 DeepSeek API 密钥。

将 Explained 连接到你自己的 DeepSeek API 账户，再由你决定何时发送阅读查询。本教程适用于 v0.2.0。

开始阅读 02

读懂研究文章，接住原来的思路。

以 HTML 研究文章为例，从一个不熟悉的词句出发，再回到作者的论证。

开始阅读 03

结合原来的语境，理解一个词句。

同一个词可能指向不同概念。用这个练习观察附近上下文的作用，并学会查看或关闭它。

开始阅读

设置完成，开始一篇好阅读。

打开体验文章，划选词句后点击图标，或按 Ctrl+X（Mac 为 ⌘X），开始第一次查询。
