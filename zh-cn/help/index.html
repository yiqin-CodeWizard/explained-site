需要时，帮你一下

找回顺畅阅读的节奏。

从你遇到的现象开始排查。以下步骤适用于 extension-wasm-offline v0.2.0 API 版。

本页内容

  1. 没有出现图标或解释
  2. 卡片提示 API 错误
  3. News 或更详细的解释没有来源
  4. 哪些页面可以使用
  5. 控制上下文与暂停查询
  6. 仍然无法解决？

没有出现图标或解释

  • 使用 Chrome 114 或更新版本，打开普通 HTML 文章。安装或重新加载扩展后，请刷新已打开的页面。
  • 打开扩展工具栏，确认查询已启用、当前网站没有暂停。尚未设置密钥时，先完成 API 设置。
  • 在阅读正文中划选一小段词句，然后点击小图标，或按 Ctrl+X（Mac 为 ⌘X）。仅划选或复制不会发送请求。
  • 输入框和编辑器中的快捷键保留正常剪切行为；解释快捷键仅用于支持的阅读选区。
  • 设置 DeepSeek API 密钥
  • 打开一篇体验文章

卡片提示 API 错误

  • 缺少密钥或密钥无效：从扩展工具栏打开 API settings，填入或更换密钥。登录 DeepSeek 网站不能代替 API 配置。
  • 余额不足或没有访问权限：前往 DeepSeek 官方平台检查 API 账户余额与权限。
  • 请求过于频繁、服务不可用或超时：稍等片刻，检查网络后再点击 Retry。重复点击可能增加请求。

News 或更详细的解释没有来源

News、时效性选区以及 Explain a little more 会先调用 DeepSeek Search。搜索失败或缺少可用证据时，扩展会显示问题，不会编造实时报道。

请核对日期并打开原始来源。生成的解释与摘要可能有误。Keep it short 会恢复已缓存的简短回答。

哪些页面可以使用

当前支持普通 HTML 阅读页面。浏览器设置页、PDF 阅读器和文档编辑器不在本预览版的支持范围内。浏览器的网站访问权限设置也可能阻止扩展运行。

以 HTML 形式发布的研究文章可以用于这一阅读流程。同一篇论文在 PDF 阅读器中打开时，仍属于不支持的页面。

控制上下文与暂停查询

工具栏可以全局暂停、暂停某个网站、选择解释语言，以及开启或关闭附近上下文。开启上下文时，会随选区发送最多 600 个附近字符。

密钥和偏好保存在本机扩展存储中。阅读页脚本只能获得过滤后的设置，不能读取密钥。本机存储并不是加密保险箱。

  • 阅读完整隐私政策（英文）

仍然无法解决？

反馈时提供扩展版本、Chrome 版本、页面类型、可见错误和复现步骤。截图及 issue 中请去掉 API 密钥、私人阅读内容和账户信息。

  • 在 GitHub 反馈问题

设置完成，开始一篇好阅读。

打开体验文章，划选词句后点击图标，或按 Ctrl+X（Mac 为 ⌘X），开始第一次查询。
