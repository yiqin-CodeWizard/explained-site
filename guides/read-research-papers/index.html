A READING WORKFLOW

Read research without losing the thread.

A practical way to use Explained with research articles published as HTML. Work from an unfamiliar phrase back to the author’s argument.

On this page

  1. Start with a readable HTML article
  2. Select one obstacle to understanding
  3. Inspect what context contributes
  4. Use a longer explanation for one remaining question
  5. Return to the author’s claim

Start with a readable HTML article

Install the API edition, configure your own DeepSeek key and open an HTML article. If a publisher offers both HTML and PDF, choose HTML for this workflow: Explained does not currently run inside PDF viewers.

For a first attempt, use the DeepSeek-V4 reading in the practice room. It contains the phrase KV cache and enough surrounding prose to make the question specific.

  • Choose a practice reading
  • Install the Chrome extension

Select one obstacle to understanding

Read the sentence once before looking anything up. Highlight the unfamiliar term rather than the whole paragraph, then click the selection icon or press Ctrl+X (⌘X on Mac).

In the practice reading, try KV cache. The useful question is how that phrase functions in this sentence. Nearby context can help the model explain the intended meaning, rather than produce an unrelated general definition.

Inspect what context contributes

Open Context used in the answer card and compare it with the sentence you were reading. If nearby context is enabled, up to 600 characters may be sent with the selection.

Try turning nearby context off from the toolbar and making a new lookup. Compare which parts of the answer depend on the surrounding text. This is a reading exercise; the two generated answers may differ for other reasons too.

  • Explore the same word in different contexts

Use a longer explanation for one remaining question

If the short answer leaves a gap, choose Explain a little more. In v0.2.0 this starts a fresh web search and requests a more detailed explanation. Open relevant source links before relying on a claim.

Keep it short returns to the cached short answer. News serves a different purpose: it searches for recent developments, so use it when you want follow-up coverage rather than a definition of the original sentence.

Return to the author’s claim

  • Reread the original sentence and explain its role in your own words. A term definition alone does not establish the paper’s conclusion.
  • Separate reported measurements, comparisons and your own interpretation. Check the original paper for conditions and limitations.
  • Treat generated text as reading assistance. Verify important facts, dates and citations against the original material.
  • Model and search calls use your DeepSeek API account. Use the toolbar to pause lookups when you want uninterrupted reading.

Your next good read starts here.

Once setup is complete, open a practice article. Highlight a phrase and click its icon, or use Ctrl+X (⌘X on Mac).
